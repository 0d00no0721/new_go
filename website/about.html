项目背景

本项目在 KataGo v1.16.4 源码上实现「20路Ban选围棋」变体。由于预编译版 katago.exe 中 Board::MAX_LEN = 19，执行 boardsize 20 会直接报错，且 GTP komi 命令拒绝非整半贴目，因此必须对源码进行改造并重新编译。

核心理念是禁点 = C_WALL——即 KataGo 原生表示「棋盘外」的颜色。将禁点标记为 C_WALL 后，合法性判断、气计算、提子、劫争零改动即可正确处理（禁点天然被视为外边界）。仅需修改数子逻辑（排除 C_WALL）、神经网络输入（feature 0）与新增 3 个 GTP 命令，合计约 90 行代码改动，分散在 4 个源文件中。

技术架构

以下为 KataGo 源码改造要点（详见仓库 Agent 2 — ENGINE.md）：

改动位置 / 方式
Board::MAX_LEN 19→25katago-src/cpp/game/board.h:15
禁点数据结构 + 数子修复board.h / board.cpp（calculateArea + calculateIndependentLifeArea 各 +1 条件）
NN 输入 feature 0nninputs.cpp（7 处 fillRow 加 C_WALL 判断）
新 GTP 命令gtp.cpp：kata-set-bans / kata-clear-bans / kata-query-bans
komi 4.25-override-config ignoreGTPAndForceKomi=4.25（无需改码）
20 路网络gtpForceMaxNNSize=true（19 路网络自动 pad 到 MAX_LEN，无需改码）
analysis.cpp 仍校验半整数 komi，4.25 在 analysis 模式被拒——首期仅支持 GTP 对弈，analysis 模式二期处理。
