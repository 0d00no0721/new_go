获取加权点目围棋桌面对弈程序

WeightedGo（CLI + GUI）

Windows 64 位 · 含改造版 KataGo 引擎 + CLI 对弈工具 + tkinter GUI

前往 GitHub Releases

解压后需另行下载 KataGo 神经网络权重（约 260 MB），详见下方说明。

系统要求

项要求
操作系统Windows 10 / 11 64 位
显卡OpenCL 兼容 GPU（NVIDIA / AMD / Intel 均可）
磁盘空间约 50 MB（程序）+ 260 MB（网络权重）
网络权重需另行下载 KataGo 权重（19 路，如 官方下载 的 28 层网络）
Python运行 CLI 需 Python 3.10+；GUI 需 tkinter

安装步骤

  1. 解压 release 中的 zip 到任意文件夹。
  2. 下载网络权重（必须，约 260 MB）：放与 katago.exe 同目录，并在设置中指定路径。
  3. 确认加权表：解压包自带 weight_table_final.txt（最终权重表），已配置为默认。
  4. GUI：python gui.py，首次启动弹设置对话框选择引擎/网络权重/加权表与 AI 水平。
  5. CLI：python cli_player.py --mode human，与 AI 对弈一局；或 --mode aivai 观战 AI 对 AI。

CLI 用法

# 人 vs AI（黑先手，默认贴目 7.5，默认加载 weight_table_final.txt）
python cli_player.py --mode human

# 人执白
python cli_player.py --mode human --color W

# AI vs AI 观战
python cli_player.py --mode aivai

# 查询任意点权重（如天元）
python cli_player.py --query-weight K10

# 复盘 SGF（含加权分）
python cli_player.py --sgf-in 对局.sgf

配置说明

GUI 设置保存在 settings.json（与脚本/exe 同目录）：

参数默认说明
engine_pathdist_opencl/katago.exe引擎文件路径
model_path28b.bin.gz网络权重路径（需自行下载）
config_pathdefault_gtp.cfg引擎配置路径
weights_pathweight_table_final.txt加权表路径
komi7.5贴目（标准中国贴目）
maxVisits800KataGo 最大搜索访问数
maxTime10.0思考时间上限（秒）
numSearchThreads20搜索线程数（按 GPU 调）
ponderingEnabledfalse后台思考（占 GPU）
game_mode人vsAI人vsAI / AIvsAI / 人vs人
show_heatmapfalseGUI 是否叠加权重热力图
